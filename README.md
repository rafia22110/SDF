# אִיֵּי אוֹר | לוח למידה אינטראקטיבי ועולם למידה עתידני (`Presentation`)

ברוכים הבאים למאגר הרשמי והמחודש של **אִיֵּי אוֹר** — מערכת חינוכית אינטראקטיבית, בהירה ומזמינה לכיתות א׳–ו׳, המשלבת **לוח למידה אינטראקטיבי שיתופי (SmartBoard)**, **עולם של 6 איי למידה צפים ו-11 משחקים לימודיים**, ו**מרכז ניהול פדגוגי מתקדם למורה** המחובר ל-Google Workspace.

---

## ✨ עיקרי המערכת החדשה

### 1. לוח המסע והאיסוף (Interactive SmartBoard)
- **עיצוב זכוכיתי מואר ובהיר (Daylight Frosted Glass)**: ממשק רגוע, מזמין ונטול עומס חזותי.
- **מסלול מסע ב-4 תחנות**: פתיחת שיעור ⬅ איסוף פריטים מהמאגר ⬅ יצירה ומשחק ⬅ סיכום וכוכבי אור.
- **איסוף פריטים בלחיצה אחת**: מאגר פריטים מוכנים ושורת הוספה מהירה ליצירת כרטיסיות תוכן, חידות מתהפכות (Flashcards), תזכורות ומשימות כיתה.
- **מצב למידה מודרך (Guided Tour)**: סיור אינטראקטיבי מובנה המדריך מורים ותלמידים חדשים דרך תכונות הליבה של הלוח.
- **שיתוף פעולה בזמן אמת (Real-Time Collaboration)**: סנכרון חי בין כרטיסיות וחלונות פתוחים באמצעות `BroadcastChannel` ו-`localStorage`, כולל סמני משתתפים חיים ומודאל הזמנת משתתפים.

### 2. עולם 6 איי האור הצפים (Gamified Learning Islands)
כל אי כולל מנוע משחקים מותאם לשכבת הגיל (א׳–ו׳), הקראה קולית בעברית, משוב מיידי וצבירת כוכבי אור:
1. **🔤 אִי הָאוֹתִיּוֹת** — קריאה, צלילים, תנועות הניקוד וקריאה קולית במיקרופון.
2. **🧮 אִי הַמִּסְפָּרִים** — חשבון, לוח הכפל, שברים, קריאת שעון מחוגים ובלוני מספרים.
3. **📖 אִי הַמִּילִּים** — אוצר מילים, הפכים, מילים נרדפות, הרכבת מילים וזיכרון דו-לשוני.
4. **🪐 אִי הַמַּדָּע וְהֶחָלָל** — מערכת השמש, מעבדת מצבי הצבירה של המים וטבע.
5. **🤖 אִי הַחֲשִׁיבָה** — לוגיקה, השלמת סדרות ותכנות מסלול רובוט האור.
6. **🎨 אִי הַיְּצִירָה** — סטודיו פיקסל-אור ליצירת דגמים זוהרים ושמירתם בגלריה.

### 3. האזור הניהולי של המורה (Teacher Management Hub)
- **מערכת שעות גמישה משויכת לאיים (`FlexibleTimetable`)**:
  - הגדרת שיעורים לפי ימים (א׳–ו׳) ורצועות שעה גמישות הניתנות לעריכה והוספה.
  - שיוך כל שיעור לאחד מ-6 האיים הקיימים במערכת ולמשחק ספציפי מתוך האי.
  - שיגור שיעור בודד או יום לימודים שלם ישירות אל הלוח החכם בלחיצה אחת.
- **אולפן העלאת תכנים ויצירת מצגת ב-3 לחיצות**:
  - **מחולל שיעור ב-3 לחיצות (NotebookLM / מצגות מובנות)**: הפיכת סיכומי NotebookLM או תבניות שיעור מוכנות (כגון *שבעת ימי הבריאה*, *מערכת השמש*, *חינוך גופני: קפיצה לרוחק מול גובה*) לסדרת כרטיסיות חיה על הלוח.
  - **העלאה מקובץ מקומי** (`.txt`, `.csv`, `.json`, `.md`).
  - **ייבוא מ-Google Drive** (`drive.readonly`).
  - **חיבור ל-YouTube לימודי** עם נגן וידאו מוטמע בתוך כרטיסיות הלוח.
- **חיבור ל-Google Classroom ו-Gmail**:
  - טעינת קורסים ופרסום מטלות חדשות ב-Google Classroom.
  - שליחת עדכון יומי ומערכת שעות להורים ולתלמידים דרך Gmail.

## 📁 מבנה הפרויקט החדש

```text
├── index.html                        # נקודת כניסה ראשית (RTL, גופני Rubik / Secular One)

├── package.json                      # תלויות React 19, Vite, Tailwind CSS 4, Firebase, Lucide
├── src/
│   ├── main.tsx                      # אתחול React
│   ├── index.css                     # עיצוב Daylight Glassmorphism ואנימציות
│   ├── types.ts                      # טיפוסים מרכזיים (Grade, IslandId, ClassState, Profile)
│   ├── audio.ts                      # מנוע צלילים (Web Audio API) והקראה קולית בעברית (TTS)
│   ├── App.tsx                       # מעטפת ראשית וניווט בין לוח המסע, האיים, משימות וניהול מורה
│   ├── data/
│   │   └── content.ts                # מאגר 6 האיים, 11 המשחקים, השאלות לפי כיתות והעיטורים
│   ├── services/
│   │   └── workspaceAuth.ts          # אימות Google OAuth וחיבור ל-Drive, Classroom ו-Gmail
│   └── components/
│       ├── SmartBoard.tsx            # לוח הלמידה האינטראקטיבי, סיור מודרך ושיתוף בזמן אמת
│       ├── FlexibleTimetable.tsx     # רכיב מערכת שעות גמישה עם שיוך לאיי הלמידה
│       ├── TeacherPanel.tsx          # האזור הניהולי של המורה ואולפן התכנים
│       ├── GamesEngine.tsx           # מנוע 11 המשחקים והסימולציות הלימודיות
│       ├── AvatarSvg.tsx             # איורי האיים (SVG), דמויות אווטאר ואפקטים
│       └── ProfileModal.tsx          # עריכת פרופיל תלמיד וחנות כוכבי אור
```

## 🚀 הרצה מקומית וסנכרון ל-GitHub

### הרצה מקומית
```bash
npm install
npm run dev
```

### דחיפת המבנה החדש אל המאגר `rafia22110/Presentation`
חשוב: יש להריץ את הפקודות **אך ורק מתוך תיקיית הפרויקט הייעודית** (שבה נמצא הקובץ `package.json`), או להשתמש בכפתור ה-GitHub המובנה בסרגל העליון של AI Studio:
```bash
git init -b main
git remote add origin https://github.com/rafia22110/Presentation.git
git add index.html package.json tsconfig.json vite.config.ts metadata.json README.md src
git commit -m "feat: complete rewrite to Iyey Or Interactive Learning Board & Teacher Hub"
git push -u --force origin main
```
*(אם בטעות הרצתם `git init` בתיקיית המשתמש הראשית במחשב שלכם, הריצו `rmdir /s /q .git` ב-CMD או `rm -rf .git` ב-Git Bash כדי לבטל את מעקב ה-Git בלי לגעת באף קובץ במחשב).*
